# Pure N18 candidate API (scratch preparation; no document commits)

Snapshot uses immutable tuples of `Node`, `Cell`, `Part`, `ExplicitSet`, `ReferenceUse`, plus `SnapshotStamp(document_id, revision, epoch, resources)` (epoch is an opaque nonempty session UUID string, not a counter) and `ResourceStamp(resource_id, state_token, mesh_revision)`. `Ref(resource_id, entity_kind, local_id)` keeps the current public SelectionRef shape; cell family/native header/source metadata are separate. IDs are never keyed globally. Snapshot captures a complete dependency closure; the later session adapter must reject opaque references before creating it.

Operations return `MeshEditCandidate` with the original snapshot and sparse node/cell/set updates and removals, typed change/mapping/impact records, before/after affected-element quality, source digest and source stamp. They never mutate the snapshot or document. A later adapter must compare epoch/revision/resource token/generation, recompute/verify the plan and atomically update native resources + stale relations + Undo. Candidate views overlay sparse changes, with no full geometry copy per edit.

- `move_nodes(snapshot, positions, length_unit=...)`: absolute positions in the explicitly matching model length unit; no implicit display/native conversion.
- `merge_nodes(snapshot, mapping, tolerance, length_unit=..., approvals=...)`: exact selected source→keeper pairs only; no closest search, chained maps, midpoint movement or unrequested IDs. Keeper coordinates survive. Each distance must be <= tolerance. Crossing source resources, component memberships or contact-side roles requires an exact additional approval for that pair and all affected contact conditions. Sets/loads are not automatically transferred.
- `delete_elements(snapshot, refs, orphan_policy='keep'|'delete_new')`: remove only selected cells; only newly orphaned connectivity/orientation nodes may be deleted. Existing orphan nodes survive. Dangling set/condition references remain in impact records and require explicit reconnection; no quiet load discard.
- `flip_shell_normals(snapshot, refs)`: SH3N `(0,2,1)`, SHELL `(0,3,2,1)`; preserve first node, element identity and ownership. Directed surfaces/material/condition references require review.
- `reassign_parts(snapshot, assignments)`: exact element→existing compatible part; membership/physical property impact is separate from set editing.
- `reassign_set(snapshot, set_ref, members)`: exact replacement of one explicit set membership with verified typed same-kind refs; it is not component ownership editing.

The last two functions implement one of the six fixed operation families. CAD size/remesh is the sixth family and remains in the existing worker/session integration, outside this pure module.

Quality: finite coordinates, resolved/unique connectivity, duplicate-cell detection, nonzero line/beam orientation; existing triangle/tet mean-ratio with signed tet volume; quad signed corner Jacobians/planarity; BRICK8 27-point trilinear Jacobian plus 8-point volume and outward face tests. Sampling is an explicit bounded validity gate, not a proof for arbitrary warped mappings. Source tokens, mesh generations and reference-impact checks are not replaced by equal native IDs or coordinates.

`merge_approvals` and `merge_tolerance` are retained in the candidate; orphan handling retains its explicit policy. `affected_resources` covers sparse writes, while `mesh_revision_resources` identifies geometry generations. This bounded snapshot uses one immutable Ref/Node per entity and indexes it once; sparse edits do not establish the N17 million-element memory budget. The native adapter must parse BEAM orientation-only n3 separately because display projection intentionally contains only the two mechanical endpoint nodes.
