# 선택·가시성 조사 결과

이번 한정 수집은 끝냈다. **23개 원문/API/코드 URL, 6개 이미지, 14개 기능 묶음, 8개 필수 coverage**를 `domains/selection.json`에 연결했다. 제품 실행·영상을 관찰한 결과가 아니며 전체 작업 재현 준비 완료로 판단하지 않는다. DB나 새 모델·GUI 코드는 만들지 않았다.

## 찾은 방향

- QGIS는 표·지도 선택을 feature ID로 연결하고, 표의 cursor·행 선택·행 필터·지도 표시를 구별할 좋은 사례다. 여러 대상의 속성이 다를 때와 사용자가 바꾼 필드를 구별하는 화면/문서도 확보했다.
- ParaView는 같은 화면의 데이터여도 point/cell association, 원본 source/output port, visible/through pick, query/ID 선택을 명시한다. 저장되는 집합과 일시 선택을 구분할 질문이 구체화됐다.
- Blender 공식 소스에서는 선택·숨김의 view-layer 범위와 active object의 별도 참조를 확인했다. 사용자 문서를 직접 열지 못했으므로 UI 경로·단축키까지 재현한 근거로 쓰지 않는다.
- 겹친 후보를 명시해 고르는 문제는 Rhino8 공식 도움말로 보완했다. preview·후보 순환·확정·취소를 별도 상태로 다룬다. 그 선택 backend나 정렬 구현을 확보한 것은 아니다.

이 자료에서 가져올 것은 일시 상태의 의미, 조작의 구분, API의 연결 책임이다. GIS layer·Blender collection·ParaView dataset을 CAE part/assembly/solver entity로 바꾸어 부르는 것만으로 재사용되는 것은 아니다. solver native 번호, 재메시 후 참조, 다중 DOF와 분석 활성 상태에는 별도의 CAE 근거가 필요하다.

## 교차 검토에 넘길 것

셸 담당과 확인한 경계: action의 활성 표시는 실제 변경 명령의 유효성 검사를 대신하지 않는다. 같은 model을 바라보는 여러 view도 선택 동기화를 따로 연결해야 한다. dock visibility는 tab의 활성 여부까지 포함할 수 있어 model entity hide와 같은 뜻으로 쓰면 안 된다. 문서 담당에는 일시 선택과 저장 참조를 분리하고, 대상 삭제·Undo 뒤 draft/선택 복원을 독립 확인할 항목으로 넘긴다.

QGIS 다중 편집 form은 Apply changes뿐 아니라 왼쪽 패널의 다른 feature 클릭도 적용 trigger로 명시한다(D02 §12.2.4.4 step5). 이 정책을 viewport 선택 변경·대상 삭제까지 일반화하지 않는다.

모든 필수 묶음을 근거 또는 공백으로 기록했지만, occlusion 후보 정렬·일부 대상 validation 실패·대상 삭제 중 draft·성능·CAE instance 변환·IME/혼합 DPI는 미확인이다. 이 공백을 기존 제품의 자동 보장으로 채우지 않는다. 자료의 정상 동작 설명은 당사 구현의 검증 결과가 아니다.

## 출처와 화면의 한계

QGIS 문서는 3.40 경로/API3.40.0을 사용했다. 화면은 공식 문서 저장소 `3d80e314bc11bd3d79e4959fd66f93ac59f2bd2a`의 PNG 원본이다. 일부 화면은 오래된 OS 장식을 포함하므로 문서 버전이 캡처 앱 빌드·DPI를 뜻하지 않는다. 원본 해상도는 JSON에 기록했고 앱 디자인 토큰으로 확정하지 않았다.

ParaView는 5.13.3 문서/소스를 연결했다. Blender는 `v4.5.3` 소스만 직접 확인했다. Rhino8 사용자 도움말과 2018 개발자 예제, Rhino9 API 참조는 각기 다른 근거다. API의 Since5.0 표시는 Rhino8 동일 동작을 이번에 직접 확인했다는 뜻이 아니다. 원문 전체·벤더 프로그램·아이콘을 제품 배포물로 편입하지 않는다.

QGIS·ParaView 원문은 web 경로로 읽었으나 직접 HTTP 다운로드는403이었다. Blender 문서 open은402였고 대체 locale/버전도 실패해 더 반복하지 않았다. 검색 결과만 나온 페이지는 확보 문서 수에 넣지 않았다. 화면6개는 공식 공개 문서 repo에서 확보해 실제 시각 확인했다. 다른 제품의 이미지 원본은 이번 범위에서 보유하지 못했다.
