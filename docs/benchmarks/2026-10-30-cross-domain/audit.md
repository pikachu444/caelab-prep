# 통합 확인과 종료 범위

## 수행한 확인

root는 여섯 분야 JSON의 source/asset/pattern/coverage ID 연결, 전역 ID 중복, 실제 보유 파일·이미지 치수·등록 SHA256, 실제 실행 검증 false를 확인했다. 오류는 없었다. 원문 URL은 fragment 제거·trailing slash·GitHub raw/blob 주소를 정규화해 집계했고, 이미지 수는 파일 SHA256으로 중복 제거했다. 고정 버전·언어·query 차이는 임의로 합치지 않았다.

root는 jobs 분야의 공식 원문 14개를 직접 읽고 이미지 3개를 확인했다. 다른 분야에서는 Qt Creator 단축키·KDE 아이콘·Qt validator·Calc 오류 정책·Pint 온도·OCAF·FreeCAD 이름/저장 코드·PyVista 원본 ID/품질·ParaView 선택·Rhino 선택 메뉴의 핵심 원문 또는 확보한 고정 소스를 대조했다. 전체 원문 124개를 root가 모두 재독했다고 주장하지 않는다.

root가 실제로 다시 연 이미지는 13개다: jobs-S01–03, engineering-input-S04/S08, shell-S01/S08, document-S05/S08, selection-S03/S04, mesh-data-S04/S06. 수집 담당은 등록 이미지 전체를 각각 시각 확인했고 Astra는 별도 표본과 전체 메타데이터를 확인했다. 원본 해상도의 관측을 Qt logical pixel·font·실제 DPI 토큰으로 확정하지 않았다.

Astra는 [독립 결과](discussion/astra-findings.md)에 공식 원문 표본·이미지 표본·전체 등록 검사와 경계별 판정을 기록했다. 셸 담당은 통합 README/synthesis를 별도로 읽어 범위·과장 여부를 검토했다. 이 검토에서 기존 계획의 결정까지 미결정으로 되돌리지 않도록 문구를 수정했다. 기존 validation·stale 거부·후보 채택 계약은 유지한다.

## 수량과 의미

- 원문 등록 125건, 고유 URL 124개: 사용자 매뉴얼·API·코드·예제·설계 지침을 포함한다.
- 이미지 51개: 화면 25, 대화상자 14, 기술/개념 그림 12. 파일 바이트 중복은 없다.
- 기능 근거 묶음 68개. 문헌/API 좁은 지원 21, 부분 46, 공백 1이다.
- 필수 coverage 41행. 좁은 API·상태 의미 supported 5, 부분 35, 공백 1이다. 사용자 종단 검증 완료 수가 아니다.
- 기존 GUI 묶음과 exact URL/이미지 바이트 중복은 0. 의미가 비슷한 문서·다른 crop까지 독립 근거로 보증하는 수치는 아니다.

전체 source URL·등록 치수·해시·원문 위치는 `domains/*.json`, 재계산 규칙은 `summary.json`에 있다. 매뉴얼 전문·실행 파일을 오프라인 배포물에 넣지 않는다.

## 전달물 검증

최종 다운로드 묶음에는 등록된 그림과 JSON·노트·토론/감사 기록·정적 HTML 색인을 넣었다. 등록 그림/내부 링크의 실제 파일 연결과 ZIP CRC를 검사한다. HTML은 외부 스크립트·fetch·DB 없이 로컬 파일로 열 수 있는 정적 색인이다. 이번에 실제 브라우저에서 레이아웃을 실행 검사하지는 않았다.

공개 저장소에는 새 보충 경로의 텍스트/JSON과 기존 벤치마크 안내 링크만 반영한다. 제품 코드·의존성·모델/저장 계약·기존 실행 단계·DB 브랜치는 변경하지 않는다. 코드 테스트나 SDK 실행을 문서 조사 결과에 덧붙여 통과했다고 쓰지 않는다.

## 종료 판정

사전에 정한 분야·교차 경계에 근거/반례/공백을 연결하고 독립 지적을 반영하는 한정 조사 범위로 닫는다. 실제 앱 R과 연속 영상 V는 0이며 모든 pattern의 `runtime_verified`와 `full_workflow_ready`는 false다. API 지원을 기능 구현·검증 완료로 바꾸지 않았다.

원문에 없는 선택 삭제 중 draft·invalid paste 원자성·실행/취소 경합·다중 산출물 채택·재메시 참조·실제 Windows 한글/DPI·대용량 성능은 남는다. 이 공백은 조사 전체를 무기한 재개하는 조건이 아니다. 후속 구현에서 해당 기능을 선택했을 때 기존 작업서의 입력·검증·종료 조건을 적용한다. 모든 수단을 다 썼거나 상용 프로그램을 그대로 재현할 준비가 끝났다는 결론은 아니다.
